# ASCIImp4

After Effects CEP Extension — ASCII Art Motion Graphics Engine

## Install

```bash
chmod +x install.sh
./install.sh
```

Then restart After Effects and open via **Window → Extensions → ASCIImp4**.

## Features

- **8 character sets** — standard, numbers, binary, letters, symbols, blocks, dots, hex, or custom
- **Dynamic scaling** — cell size flexes with rotoscoped layer bounding box per-frame
- **8 color modes** — mono, source video, analogous, hue shift, gradient, neon, thermal, glitch
- **Analogous color generator** — hue spread, count, cycling over time
- **Post-processing** — hue shift, saturation, brightness, source video overlay blend
- **Cluster tracker** — k-means pixel clustering, bright/dark/edge/motion modes
- **Data overlay** — bounding boxes, dotted/dashed connectors, numeric labels, scan lines, corner brackets
- **Presets** — 8 built-in, save/load/export/import user presets as JSON
- **Thresholds** — luma, alpha, contrast, gamma per render

## Requirements

- After Effects CC 2021 or later
- macOS (Windows path differs — edit install.sh accordingly)
